Getting Started

Everything you need to set up your environment and start hacking.

Prerequisites

  • A GitHub account — you need access to the org repo your event organizer set up
  • GitHub Copilot access (free tier or subscription)
  • One of:
    • GitHub Codespaces (recommended — nothing to install)
    • VS Code + Docker Desktop for local dev containers
  • Basic familiarity with JavaScript/TypeScript and web applications

Note: You will not fork the repository. Your organizer provides one shared org repo. Create your own branch from main, push it to the org repo, and open pull requests back to main so GHAS/code scanning can validate your changes. Use team-{your-team-name}/challenge-work for teams, or participant/{your-name-or-team} for individual participants.

Option A: GitHub Codespaces (Recommended)

The fastest way to get started. No local setup required — everything runs in the cloud.

  1. Go to the org repo your organizer shared with you on github.com
  2. Click the green Code button → Codespaces → Create codespace on main
  3. Wait for the dev container to build and dependencies to install
  4. Open a terminal, create your branch, and start the app: 
    git checkout -b team-{your-team-name}/challenge-work
git push -u origin team-{your-team-name}/challenge-work
cd app && npm start
    Juice Shop will be available at port 3000.

Option B: Local Dev Container

If you prefer working locally with VS Code and Docker.

  1. Clone the org repo (do not fork it)
  2. Open the folder in VS Code
  3. When prompted, click Reopen in Container (requires Docker Desktop running)
  4. Create your branch and start the app: 
    git checkout -b team-{your-team-name}/challenge-work
git push -u origin team-{your-team-name}/challenge-work
cd app && npm start
