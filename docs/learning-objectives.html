Learning Objectives

By the end of this hackathon, you'll be able to confidently use GHAS and Copilot to secure real applications.

GitHub Advanced Security (GHAS)

  • Configure CodeQL analysis for JavaScript/TypeScript projects
  • Interpret CodeQL alerts and understand vulnerability classifications
  • Enable and use Dependabot for dependency vulnerability detection
  • Review and act on secret scanning alerts
  • Understand the OWASP Top 10 and how GHAS detects these vulnerabilities

GitHub Copilot

  • Use GitHub Copilot to understand and explain security vulnerabilities
  • Leverage Copilot Chat to generate secure code fixes
  • Apply Copilot suggestions to remediate CodeQL findings
  • Use Copilot to write security-focused unit tests

Application Security

  • Identify common web vulnerabilities (XSS, SQL Injection, broken auth, etc.) in a real application
  • Apply secure coding practices to an Express.js / Angular application
  • Understand why vulnerabilities exist and how to prevent them
  • Practice the "shift left" approach to security in the development workflow
